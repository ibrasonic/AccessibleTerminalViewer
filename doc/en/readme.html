AccessibleTerminalViewer

AccessibleTerminalViewer presents the currently focused terminal as a structured browse-mode document. It supports Command Prompt, Windows PowerShell, PowerShell, and Windows Terminal.

Author: Ibrahim Badawy. Last tested with NVDA 2026.3.1.

Opening the view

Place focus in a supported terminal and press NVDA+Shift+V. A browsable document opens containing the terminal text available through Windows accessibility APIs.

Navigation

  • Press H or Shift+H to move between command prompt lines.
  • Press T or Shift+T to move between detected tables.
  • Use NVDA's table navigation commands to move between table cells.
  • Press L or I to move to detected lists or list items.
  • Press Escape or activate Close to return to the terminal.

Table detection

The add-on recognizes common PowerShell Format-Table output, pipe-delimited tables, and tables that use Unicode vertical borders. Output that cannot be classified safely remains preformatted. Blank-only terminal rows and invisible terminal padding are removed.

Notes

The view is a snapshot. Close it and press NVDA+Shift+V again after terminal output changes. Only text exposed by the terminal's accessibility interface can be included. The feature is disabled on secure screens.

Updates

AccessibleTerminalViewer checks GitHub Releases shortly after NVDA starts. When a newer version is available, the add-on offers to download, verify, and install it. You can also assign a gesture to Check AccessibleTerminalViewer for updates in NVDA's Input Gestures dialog.
